# CUP2EAT image slots

Add the brand assets here using these exact filenames. The page will pick them up automatically:

- `cup2eat-logo.png` — primary logo, ideally with transparent background.
- `hero-edible-cups.png` — wide hero composition with 2–3 cups and chai/coffee.
- `chocolate-cup.png` — chocolate flavour product photo.
- `vanilla-cup.png` — vanilla flavour product photo.
- `elaichi-cup.png` — elaichi/cardamom flavour product photo.
- `story-cup.png` — lifestyle/product photo for story and applications.

Recommended: compressed WebP or AVIF versions are even faster; if you use those, update the filenames in `app/page.tsx`.
